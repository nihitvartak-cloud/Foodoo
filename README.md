# Foodo Recipe Transformer

A responsive recipe transformation app with primary and optional secondary nutrition goals. Transformations and nutrition figures are generated by the official OpenAI Node SDK's Responses API and are presented as estimates.

## Run locally

1. Install Node.js 20.12 or newer.
2. Run `npm install`.
3. Set `OPENAI_API_KEY` in the server environment, or copy `.env.example` to `.env` and set it there for local development.
4. Run `npm run dev` and open the Vite URL printed in the terminal.

The server loads `.env` from the project root (independent of the process working directory) and also supports environment variables supplied by a deployment platform. Restart the server after changing environment variables. `OPENAI_API_KEY` is read only by the server and is never sent to the browser. `OPENAI_MODEL` can optionally select another model that supports the Responses API; it defaults to `gpt-5.5`.

The `POST /api/transform-recipe` endpoint accepts a dish name and recipe, transformation mode, dietary preference, primary and optional secondary fitness goals, optional calorie and protein targets per serving, and the serving count. It returns a structured recipe and estimated nutrition breakdown. Missing or rejected API credentials produce an explicit server configuration error.

## Build

Run `npm run build` to type-check and build the frontend into `dist/`.

Nutrition and calorie comparisons are AI-generated estimates, not medical advice or a substitute for a qualified professional.
